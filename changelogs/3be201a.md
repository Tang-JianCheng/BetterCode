# 仓库生成文件清理

## 修改摘要

停止跟踪本地依赖目录，并阻止 BetterCode 运行期记忆进入版本控制。

## 详细变更

- 将 `node_modules/` 加入 Git 忽略规则，依赖安装结果继续保留在本地，由 `pnpm-lock.yaml` 负责可重复安装。
- 将 `.bettercode/memory/` 加入 Git 忽略规则，避免自动提取的项目记忆、用户上下文或认证信息被误提交。
- 从 Git 索引移除历史上已跟踪的 `node_modules` 文件，不删除开发机上的实际依赖目录。

## 验证

- `pnpm install --frozen-lockfile`
- `pnpm check`
- `git check-ignore node_modules .bettercode/memory/MEMORY.md`
- 敏感文件扫描与暂存边界检查

# BetterCode 五层权限系统 Checklist

> 每一项都通过运行代码或观察用户可见行为验证。高危命令只进入纯匹配测试或带执行探针的假工具，禁止在真实 Shell 中运行。

## 验收结果

- 结果：54/74 项已有实际证据，20 项保留待人工交互或补充矩阵验证。
- 自动化：`pnpm check` 通过，95 项测试、0 失败、0 跳过，TypeScript strict 类型检查通过。
- TUI：使用 `--permission-mode strict` 真实启动，标题正确显示权限模式，空闲 Ctrl+C 正常退出；未发送真实模型请求。
- 安全：高危命令只经过纯匹配函数与执行探针；项目配置符号链接逃逸、文件路径逃逸和永久写入失败均有自动化覆盖。
- 补丁：`git diff --check`、旧产品名扫描、CLI 非法模式、依赖和 Git 忽略规则检查通过。
- 待验收：E1-E8 等真实权限面板操作，以及清单中仍为 `[ ]` 的项目；未使用 Fake Provider 冒充人工 TUI 结果。

## 强制安全边界

- [x] **C1：六个核心工具统一判权**  
  对读文件、写文件、改文件、执行命令、找文件和搜代码分别提交有效调用，确认每次都先产生权限决定；拒绝时执行探针保持未调用。（验证：运行权限管理器与调度器测试，检查六类调用和执行计数；覆盖 AC1）

- [x] **C2：危险命令在全部模式下硬拒绝**  
  对系统根目录递归强删、文件系统格式化、裸设备写入、系统关闭或重启和典型 fork bomb 的代表字符串，分别在 strict、default、allow 模式及显式 allow 规则下判定，结果始终为 `DANGEROUS_COMMAND`，子进程探针始终未启动。（验证：运行黑名单与权限管理器测试；覆盖 AC2）

- [x] **C3：危险命令不能进入人工确认**  
  为黑名单命令提供会自动允许的权限决策器，确认决策器调用次数为零，结果仍为拒绝。（验证：运行权限管理器强制层测试；覆盖 AC2）

- [x] **C4：常用安全命令不被黑名单误伤**  
  对项目构建、测试、Git 查询、打印文本和项目内普通删除命令运行纯匹配测试，确认不命中黑名单并继续进入普通规则或模式判断。（验证：运行黑名单负例测试；覆盖 AC3）

- [x] **C5：项目内真实路径可继续判权**  
  对已存在文件和待创建文件的项目内相对路径判定，确认沙箱返回规范化项目相对目标，而不是越界错误。（验证：运行沙箱项目内路径测试；覆盖 AC4）

- [x] **C6：绝对路径和路径穿越不可授权**  
  对绝对路径和包含独立 `..` 的路径，在三档模式、显式 allow 和自动允许决策器下分别尝试，确认均返回 `PATH_OUTSIDE_ROOT` 且项目外文件不变。（验证：运行沙箱和权限管理器组合测试；覆盖 AC4）

- [x] **C7：符号链接逃逸不可授权**  
  在临时项目中创建指向项目外文件、项目外目录和悬空目标的符号链接，确认读取、写入和编辑预检均拒绝，外部目标内容保持不变。（验证：运行符号链接沙箱测试并比较操作前后文件内容；覆盖 AC4）

- [x] **C8：glob 搜索保持项目边界**  
  对绝对 glob、包含 `..` 的 glob 和项目内 glob 分别调用找文件或搜代码，确认前两者拒绝，项目内调用只返回项目相对结果且不跟随外部符号链接。（验证：运行沙箱与六工具测试；覆盖 AC4）

## 规则与配置

- [x] **C9：工具级规则准确匹配**  
  配置不带括号的工具规则，确认它匹配该工具全部调用但不匹配其他工具。（验证：运行规则解析与引擎测试；覆盖 AC5）

- [x] **C10：精确规则准确匹配**  
  配置普通文本参数或路径规则，确认只匹配完整相同目标，不匹配前缀、后缀或相似路径。（验证：运行规则解析测试；覆盖 AC5）

- [x] **C11：glob 规则准确匹配**  
  使用 `run_command(git *)`、路径 `*`、`**`、`?` 和字符类模式，确认只匹配预期完整目标，不发生隐式 basename 匹配。（验证：运行规则解析与 matcher 测试；覆盖 AC5）

- [x] **C12：特殊字符可生成精确授权**  
  对含 `*`、`?`、方括号和反斜杠的真实目标生成会话或永久规则，确认转义后只匹配原目标，不扩大为 glob。（验证：运行规则转义往返测试；覆盖 AC5）

- [x] **C13：非法规则失败关闭**  
  分别提交未知工具、空表达式、非法 effect、错误括号、未知字段和错误配置版本，确认产生带文件或规则位置的诊断，不形成 allow。（验证：运行规则解析和配置加载错误测试；覆盖 AC5、AC8）

- [x] **C14：精确规则优先于宽泛规则**  
  在同一层同时配置工具级、glob 和精确冲突规则，确认 exact > glob > tool。（验证：运行同层具体程度测试；覆盖 AC6）

- [x] **C15：更具体 glob 优先**  
  在同一层配置多个都能命中的 glob，确认非通配字面字符更多的规则获胜。（验证：运行 glob 具体程度测试；覆盖 AC6）

- [x] **C16：同具体程度以后声明为准**  
  在同一层配置具体程度相同但结果冲突的规则，确认靠后的规则稳定获胜，多次加载结果一致。（验证：重复运行规则引擎确定性测试；覆盖 AC6）

- [x] **C17：跨层优先级固定**  
  构造 user、project、local、session 四层冲突规则，确认优先级严格为 session > local > project > user，高层明确结果不会被低层覆盖。（验证：运行跨层组合测试；覆盖 AC7）

- [x] **C18：缺失配置视为空层**  
  在三个配置文件都不存在时启动权限模块，确认无配置诊断，规则计数为零，后续行为由权限模式决定。（验证：运行配置缺失测试；覆盖 AC8）

- [ ] **C19：单层损坏不产生授权**  
  分别损坏 user、project 和 local YAML，确认损坏层整体不参与匹配，其他有效层仍可工作，界面状态能看到文件位置和错误原因。（验证：运行配置加载测试并观察 `/permissions` 状态；覆盖 AC8）

- [x] **C20：权限配置不泄露正文**  
  在损坏配置中放入测试敏感值，确认结构化错误、Agent 事件和界面诊断只显示必要位置与原因，不回显完整配置或工具敏感参数。（验证：运行诊断脱敏测试并检查事件快照；覆盖 AC8、AC15）

## 模式与人工确认

- [ ] **C21：严格模式拒绝未命中调用**  
  在空规则配置下切换 strict，提交有效读类和副作用调用，确认都不请求用户、都不执行，并返回规则未命中的拒绝原因。（验证：运行模式测试，并在 TUI 使用 `/permissions strict` 观察一次；覆盖 AC9）

- [ ] **C22：默认模式请求确认**  
  在空规则配置下切换 default，提交有效调用，确认出现且只出现一个权限请求，工具在用户选择前未执行。（验证：运行可控决策器测试，并在 TUI 使用 `/permissions default` 观察；覆盖 AC9）

- [x] **C23：放行模式允许未命中调用**  
  在空规则配置下切换 allow，提交普通项目内调用，确认不出现权限请求并执行成功；显式 deny、黑名单和沙箱仍优先拒绝。（验证：运行三档模式组合测试；覆盖 AC9）

- [ ] **C24：模式切换只影响后续调用**  
  空闲时在 strict、default、allow 间切换，确认状态立即更新；Agent 正在运行时切换被拒绝，已经判定或执行的调用不被追溯改变。（验证：运行 ChatManager 模式测试并观察 TUI 状态；覆盖 AC9）

- [x] **C25：仅本次允许不创建规则**

- [x] **C26：本会话允许立即复用**  
  默认模式选择 `allow_session` 后当前调用执行，同一会话再次提交相同目标时由 session_rule 直接允许，不再确认。（验证：运行会话授权测试；覆盖 AC11）

- [ ] **C27：清空会话移除临时授权**  
  创建会话授权后执行 `/clear`，再次提交相同调用时重新确认；当前权限模式和持久化规则仍保留。（验证：运行 ChatManager 清理测试并执行一次 TUI 流程；覆盖 AC11）

- [x] **C28：永久允许写入项目本地配置**

- [ ] **C29：永久授权重启后生效**  
  写入永久授权后重新创建权限模块或重启 BetterCode，确认相同目标由 local_rule 直接允许，不再请求确认。（验证：运行重新加载测试，并执行一次 TUI 重启流程；覆盖 AC12）

- [x] **C30：重复永久授权保持幂等**  
  对同一目标连续选择永久允许，确认项目本地 YAML 不出现重复规则，原有规则顺序和注释尽量保留。（验证：运行配置持久化幂等测试；覆盖 AC12）

- [x] **C31：永久写入失败时不执行**  
  使用损坏或不可写的项目本地配置触发 `allow_permanent`，确认返回 `PERMISSION_CONFIG_ERROR`、原文件字节不变、工具未执行，也没有降级为会话允许。（验证：运行配置失败注入测试；覆盖 AC12、AC15）

- [x] **C32：用户拒绝不执行工具**

- [ ] **C33：等待确认期间可取消**

- [x] **C34：迟到和重复决定不误执行**

## 动态面板

- [x] **C3：输入 `/` 自动出现面板**
  输入框以 `/` 开头即渲染候选，输入 `/pe` 实时过滤到 `/permission` 等匹配项。（验证：InputBox 渲染测试；覆盖 AC1）

- [x] **C4：短描述与完整描述**
  未聚焦行只显示短描述；方向键聚焦后在其下方展示完整描述并自动换行，不超出终端宽度。（验证：InputBox 渲染测试；覆盖 AC2）

- [x] **C5：键盘交互完整**
  Tab 单候选补全、多候选进入面板；Enter 对完整命令直接执行、对部分输入选中候选；Esc 收起面板。（验证：InputBox 交互测试；覆盖 AC3）

- [x] **C6：降级可用**
  ASCII 模式不输出 `❯` 等 Unicode 装饰；55/80/120 列下候选与描述均不越界。（验证：InputBox 渲染测试；覆盖 AC4）
